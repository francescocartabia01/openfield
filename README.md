# openfield 🐁

**CS50R (Introduction to Programming with R) - Final Project**

As a final project for this course, I developed `openfield`, a custom R package designed to automate the scoring, statistical summary, and plotting of behavioral data from Open Field Tests.

## Features:
* **Raw tracking data processing:** automates the extraction of behavioral metrics from Open Field Test raw data.
* **Automated statistical summaries:** computes means, standard deviations, and Standard Error of the Mean (SEM).
* **Publication-ready data visualization:** generates standardized plots for Open Field Test behavioral metrics.
